## 📊 Project Overview

This project is a **full Excel-based data analysis dashboard** built using a real-world laptop dataset.

It explores how different laptop specifications such as CPU, GPU, RAM, storage type, and brand influence pricing in the market.

The goal is to simulate a real data analyst workflow using **Microsoft Excel only**, including:
- Data cleaning
- Feature engineering
- Pivot table analysis
- Data visualization
- Interactive dashboard creation

---

## 📁 Dataset Description

The dataset contains information about laptops sold on a Spanish e-commerce platform.

### 🔑 Features:

- 💻 Laptop Name
- 🏷️ Brand
- 📦 Model
- 🧠 CPU (Processor)
- 🎮 GPU (Graphics Card)
- 🧮 RAM (GB)
- 💾 Storage (HDD / SSD / eMMC)
- 📏 Screen Size
- 📱 Touchscreen Support
- 🔄 Status (New / Refurbished)
- 💰 Final Price

---

## 🎯 Project Objectives

This analysis aims to answer:

- What factors influence laptop prices?
- Do technical specifications increase price significantly?
- Is there a difference between new and refurbished laptops?
- How does RAM, CPU, and storage type affect pricing?
- Which brands dominate the premium segment?
